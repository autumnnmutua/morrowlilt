# 语言测评与错题巩固

## 产品边界

本模块提供词汇、短语、搭配和语境理解练习，不包含写作题。题目来自项目题库，不复制或镜像受限制的试题材料。

“近期不重复”是工程规则：创建会话时，服务端对按顺序排列的题目 ID 计算 SHA-256 `question_fingerprint`，并与该 profile 最近 20 个 `in_progress` 或 `completed` 会话比较。完整指纹相同则最多重采样 16 次。题库或近期组合空间不足时允许调整顺序、题型或用同难度题目补足，API、UI 和结构化日志返回降级原因。

## 数据与安全边界

- `quiz_sessions` 保存 256-bit Web Crypto 种子、设置、顺序指纹、状态、汇总和降级原因。
- `quiz_session_questions` 是不可变会话快照；`public_json` 只含题干、选项、难度、主题和来源，标准答案、可接受答案及解释存放在独立服务端字段。
- `quiz_answers` 每题唯一且会话内幂等，保存规范化答案、评分、错误原因和用时。
- `mistake_book` 保留当前 mastery、连续正确与复习日期；达到 80 且连续正确至少 2 次后改为 `mastered`，不删除记录。
- `mistake_book_events` 永久保留每次错误或正确复测的 mastery 前后值。

浏览器在报告生成前不会收到标准答案、可接受答案或解释。测试夹具和示例均使用匿名 profile 与项目题库，不含真实个人数据。

## 题型

| 类型           | 输入     | 评分重点                                          |
| -------------- | -------- | ------------------------------------------------- |
| 英译中语境选择 | 单选     | 词义是否匹配上下文                                |
| 中文提示拼写   | 文本     | NFKC、大小写、标点规范化；较长词允许 1 个编辑距离 |
| 完形填空       | 文本     | 标准答案和明确列出的可接受替代表达                |
| 搭配选择       | 单选     | 学术与正式语境中的自然搭配                        |
| 短语释义       | 单选     | 短语在上下文中的准确含义                          |
| 错题复测       | 原题变体 | 优先抽取 active 错题，不足时明确降级补题          |

## API

- `GET /api/quiz/sessions`：读取最近可恢复的进行中会话。
- `POST /api/quiz/sessions`：创建会话；需要 `Idempotency-Key`。
- `GET /api/quiz/sessions/:id`：读取安全会话快照。
- `POST /api/quiz/sessions/:id/answers`：保存单题答案与毫秒用时；需要 `Idempotency-Key`。
- `POST /api/quiz/sessions/:id/complete`：完成会话、生成报告并更新错题；重复请求返回同一报告。
- `GET /api/quiz/sessions/:id/report`：读取已完成报告。
- `GET /api/quiz/reports/latest`：读取最近报告。
- `GET /api/mistakes`：读取 active 与 mastered 错题摘要。

## 三会话示例（匿名固定夹具）

集成测试以三个不同的 256-bit 固定种子创建三个 6 题会话，测试结果如下；完整指纹由测试实时计算并断言三者互不相同。

| 匿名会话          | 作答策略           | 题集差异             | 正确数 | 报告重点                           |
| ----------------- | ------------------ | -------------------- | -----: | ---------------------------------- |
| fixture-session-A | 全部使用可接受答案 | 独立种子与顺序指纹   |  6 / 6 | 无明显薄弱项，建议间隔复习         |
| fixture-session-B | 奇偶题交替正确     | 与 A、C 完整指纹不同 |  3 / 6 | 输出题型、主题、每题用时和错误原因 |
| fixture-session-C | 全部使用错误答案   | 与 A、B 完整指纹不同 |  0 / 6 | 所有错误进入错题簿并形成复习建议   |

三会话的单题用时依次为 1000、1250、1500、1750、2000、2250 ms，总用时 9750 ms；测试同时验证报告汇总等于逐题计时之和。

## 降级码

- `INSUFFICIENT_MISTAKES_FILLED_FROM_BANK`：active 错题不足，使用同难度题目补足。
- `INSUFFICIENT_QUESTION_BANK`：选定题型无法达到请求题量，返回实际题量。
- `RECENT_FINGERPRINT_SPACE_EXHAUSTED`：有限重采样后仍命中近期完整指纹。

这些码会作为 `degradedReason` 返回并以 `quiz_generation_degraded` 结构化日志记录；日志仅含会话 ID、请求/实际题量和原因，不含答案或个人数据。
