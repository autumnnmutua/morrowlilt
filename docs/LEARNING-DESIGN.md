# 每日英语学习内容设计

## 1. 学习目标

每日学习包同时服务两类目标：一是 C1–C2 / 雅思及以上难度的词汇、语法与阅读理解；二是朋友聊天、线下互动、游戏和网络社区中自然、得体的实用表达。内容不设置口语录音、口语计时或写作题。

每个业务日固定一份 D1 快照，同一天重复打开保持一致。句子、每日词汇和实用表达的规范化 SHA-256 会写入长期唯一登记表，完全相同的组件不能在以后日期再次入库；最近 30 次内容还会做整体相似度检查，降低换词式近似重复。网页和 23:00 邮件读取同一条 `daily_content`。

## 2. 每日学习包

每包至少包含：

- 一条完整英文句子及自然中文释义；
- 语法、语用注意和微练习；
- 常用搭配与替换表达；
- 三个 C1–C2 词汇，逐项给出精确词性、完整中文释义、英文释义、英文例句、例句中文翻译和使用注意；
- 三个地道实用表达，给出多个中文含义、语义核心、至少两个真实场景、误用提醒、相近表达对比和正式语境迁移。

实用表达优先选择有稳定使用价值、不过度追逐短期网络梗的内容。中文解释应说明为什么自然、什么场景能用、哪些直译会显得生硬，而不只给一行翻译。

## 3. 难度与质量

- 词汇与句法以 C1 为下限，可包含 C2 项目，但不得为了显难而使用罕见、失真的表达。
- 例句必须自然、完整，并与所解释义一致。
- 中文释义按语境拆分，不能把多个明显不同的义项压成一个含糊词。
- 俚语、缩写和游戏表达必须标注语域；有冒犯风险或只在小圈子成立的表达不进入默认内容。
- 微练习采用翻译、改写、选词或情境判断，不生成写作作文题。

## 4. 词典与复习衔接

每日词汇可进入收藏或复习队列。独立词典完整显示在线 Provider 与 Open English WordNet 提供的全部 entries、词性和 senses，并补充中文释义、例句翻译、词形和动词时态。查错或未掌握的项目进入错题/复习流程，连续答对后提升 mastery，但保留历史。

联想词同时使用搜索历史、本地大词库和可用的在线联想源。第三方断线时仍可在 D1 大词库中查词；用户设备完全断网时只读最近缓存，不伪造新查询或写操作成功。

## 5. 内容审查

1. 结构校验：字段、长度、语言与纯文本约束。
2. 安全清理：拒绝 HTML、脚本、个人信息和禁用字段。
3. 语言复核：词性、义项、搭配、例句与中文对应关系。
4. 重复复核：长期拒绝完全相同的句子、词汇和实用表达，并比较最近 30 次内容的整体相似度。
5. 场景复核：表达真实、得体，说明语域与误用风险。
6. 发布后纠错：管理员再生成必须显式触发并保留审计；用户学习记录不因内容修订被删除。

## 6. 验收

- 同一天多次打开得到相同快照；跨日内容指纹不同，完全相同的句子、词汇和实用表达不能再次入库。
- 首页与邮件逐项对应同一 `daily_content`。
- 每个每日词汇都有词性、中文释义、英文释义、双语例句和使用注意。
- 每个实用表达都有多个含义、场景、误用提醒和替代表达对比。
- 测评不包含写作题，站内不存在口语练习入口或后台口语生成请求。
- 查词不截断词性或义项；联想词支持键盘与屏幕阅读器；第三方词典失败时可回退 D1 大词库。
