## 1. 命名初筛与风险说明

### 1.1 初筛方法

本轮是发布前的“knock-out search”：检索完全匹配名称、拆词组合、语言学习应用和教育服务近似名称，同时核对 IELTS 官方的商标边界。它只能发现明显风险，不能替代商标律师或中国、英国、美国及计划运营地区商标局的正式近似检索。

IELTS 官方声明明确说明 `IELTS`、IELTS 标识和“雅思”等属于 IELTS Partners 的注册商标或商标；IELTS 由 British Council、IDP IELTS 与 Cambridge University Press & Assessment 共同拥有。因此它们只能在必要的描述性正文中出现，不能构成本产品主品牌、Logo、域名主干或合作暗示。[IELTS 官方版权与商标声明](https://ielts.org/legal/ielts-copyright-and-trade-mark-statement)

USPTO 的官方检索指南也提醒：仅搜索完全一致名称不够，还应检查外观、读音、含义、商业印象和相关商品/服务，并建议复杂项目委托商标律师完成清查。[USPTO 商标清查指南](https://www.uspto.gov/trademarks/search/federal-trademark-searching)

### 1.2 三个候选名称

#### A. MorrowLilt / 晨律（推荐）

- **构词**：`morrow` 指向明日与持续积累，`lilt` 指向自然的语言节奏。
- **推荐理由**：与“每天不同、未学不丢、逐日结清”的产品机制高度一致；不把考试名当品牌；声音柔和但不幼稚，适合薄荷绿与湖蓝系统。
- **中文副标题**：每天一小步，英语更从容。
- **初筛结果**：截至 2026-08-20，本轮公开网页完全匹配检索未发现明显同名语言学习产品或教育公司。
- **风险等级**：低至中。无明显命中不等于可注册，仍需检索 `Morrow Lilt`、近似读音、拆词商标及教育软件相关类别。

#### B. PaceLilt / 语步

- **构词**：`pace` 强调个人节奏，`lilt` 保留语言韵律。
- **推荐理由**：适合表达不以连续打卡施压、允许积压后再整体结清的体验。
- **中文副标题**：按自己的节奏，把英语走稳。
- **初筛结果**：未发现明显完全同名语言学习产品；但 `Pace` 在教育机构和软件命名中较常见，显著性较弱。
- **风险等级**：中。需重点检查教育、在线软件及相近 `Pace + 语言` 组合。

#### C. LexiSprig / 词芽

- **构词**：`lexi` 指向词汇，`sprig` 指向每天长出一点的新芽。
- **推荐理由**：亲和、易形成词汇生长隐喻，适合错题巩固与每日内容。
- **中文副标题**：让词汇每天生长一点。
- **初筛结果**：未发现完全匹配名称，但 `Lexi` 前缀在词汇学习产品中拥挤，且已有 Sprig Learning 的语言学习业务，存在近似商业印象风险。
- **风险等级**：中至高。只有在正式近似检索确认安全后才考虑使用。

### 1.3 排除过的明显风险方向

- `Tideword` 已存在服饰品牌/历史商标记录，不采用。
- `VerbaLoom` 已出现培训公司名称，不采用。
- 含 `IELTS`、`雅思`、`Cambridge`、`British Council` 或 `IDP` 的主品牌、组合 Logo、域名和社交账号名全部排除。

### 1.4 发布前人工核验

在购买域名、申请应用商店名称、制作 Logo 或公开推广前，负责人必须：

1. 在中国国家知识产权局及目标运营国家/地区商标库检查完全相同和近似文字。
2. 覆盖教育服务、可下载软件、SaaS、出版物及可能相关类别，不只检查一个类别。
3. 检查大小写、连写/分写、读音相近、中文译名和图形标识。
4. 检查公司名、域名、应用商店、社交账号及仍在使用的未注册品牌。
5. 由有资质的商标代理人或律师给出正式清查意见。本文件不是法律意见。

## 2. 品牌表达

### 2.1 品牌核心

MorrowLilt 帮用户把考试能力训练拆成可完成、可追溯、不会静默消失的每日节奏。品牌不制造“断签焦虑”，不夸大分数，不用权威口吻替用户做决定。

关键词：**从容、清楚、持续、诚实、可掌控**。

### 2.2 品牌独立性

品牌和内容运营保持独立，不使用考试机构的视觉资产、合作措辞或成绩保证。站内不重复展示工程性质的免责声明；必要的版权与第三方信息集中放在说明文档中。

### 2.3 语气指南

| 场景     | 应该                                            | 避免                              |
| -------- | ----------------------------------------------- | --------------------------------- |
| 日常引导 | 平静、具体：“今天有 3 天待学内容，可分组查看。” | 施压：“你已经断签 3 天，快补救！” |
| 完成动作 | 说明范围：“结清截至今天的整个待学包。”          | 模糊：“打卡成功。”                |
| 未学习   | 中性：“保持未学习，内容明天会继续保留。”        | 道德评判：“偷懒一天。”            |
| 测试结果 | 解释事实：“8/10，两个词进入巩固。”              | 冒充官方：“预计官方 7.5 分。”     |
| 错误     | 给下一步：“词典服务暂不可用，请稍后重试。”      | 责怪用户或暴露技术堆栈            |
| 生成内容 | 明确来源：“生成式练习建议，仅供练习参考。”      | “权威答案”“官方评分”              |

中文使用短句和明确动词；英文用于品牌、词汇例句和必要标签，不为了“国际感”混入无意义英文。

## 3. 设计原则

1. **内容先于装饰**：日期、待学范围、题目和释义是视觉主角，不使用大幅无关插画。
2. **状态必须可读**：成功、警告、错误均有文字、图形/边框和颜色三重提示。
3. **积压可折叠但不可消失**：每个未结清日期始终有可见摘要、项目数和状态。
4. **一个主要动作**：页面可以有多个入口，但每个任务区只突出一个主动作。
5. **移动端不减业务含义**：手机可以重排或折叠，不得删除日期、来源、状态或结清范围说明。
6. **克制的清新感**：暖白为底，薄荷绿承担动作，湖蓝承担信息；不用彩虹渐变、装饰性 Emoji 或无意义指标卡。

## 4. 设计 Token

代码来源：`src/styles/tokens.css`。新增组件只能引用语义 token，禁止在组件内临时创造同义颜色和间距。

### 4.1 色彩

| Token                    | 浅色      | 深色      | 用途              |
| ------------------------ | --------- | --------- | ----------------- |
| `--color-canvas`         | `#f7f4ec` | `#101816` | 暖白/深墨页面背景 |
| `--color-surface`        | `#fffdf8` | `#17211f` | 主内容面          |
| `--color-surface-muted`  | `#edf3ef` | `#1d2a27` | 薄荷灰辅助面      |
| `--color-heading`        | `#18322f` | `#f4f8f5` | 标题              |
| `--color-text`           | `#304946` | `#dce7e2` | 正文              |
| `--color-text-muted`     | `#566966` | `#a8b8b2` | 次级文字          |
| `--color-primary`        | `#2d7568` | `#78b9a8` | 低饱和薄荷绿主色  |
| `--color-primary-strong` | `#235d54` | `#9bcdbf` | Hover/强调        |
| `--color-info`           | `#3d708a` | `#82b4cb` | 湖蓝信息色        |
| `--color-success`        | `#267054` | `#72bd96` | 成功              |
| `--color-warning`        | `#8b5d18` | `#e6ba63` | 警告              |
| `--color-error`          | `#a6423f` | `#ed918d` | 错误              |
| `--color-focus`          | `#176f91` | `#8ad3ef` | 可见焦点环        |

浅色正文与背景、主色按钮与按钮文字应达到 WCAG AA；不可把低饱和理解为低对比度。

### 4.2 字体

- 标题：`Source Serif 4` / `Noto Serif SC`，本地不可用时回退到 `Songti SC` 和 serif。
- 正文：`Noto Sans SC`，回退到 `Microsoft YaHei` 和 sans-serif。
- 数据：等宽数字特性 `font-variant-numeric: tabular-nums`，不另引装饰性等宽字体。

| Token              | 字号/行高        | 用途                     |
| ------------------ | ---------------- | ------------------------ |
| `--font-size-xs`   | 12/1.5           | 辅助标记，不承载关键正文 |
| `--font-size-sm`   | 14/1.6           | 次级说明                 |
| `--font-size-body` | 16/1.75          | 移动与桌面正文           |
| `--font-size-lead` | 18/1.65          | 导语、题干               |
| `--font-size-h3`   | 20/1.4           | 卡片/组标题              |
| `--font-size-h2`   | 28/1.25          | 页面区块标题             |
| `--font-size-h1`   | 40/1.12，手机 32 | 页面主标题               |

### 4.3 尺寸与效果

- 间距：`4, 8, 12, 16, 24, 32, 48, 64px`。
- 圆角：控件 `8px`、内容块 `12px`、主要面板 `16px`、胶囊 `999px`。
- 阴影：默认面板仅 `0 1px 2px`；浮层使用 `0 16px 40px`，不让每张卡悬浮。
- 边框：`1px solid`，依赖 `--color-border`；分组优先用留白和分隔线。
- 最大正文宽度：`72ch`；应用内容最大宽度 `1200px`。
- 触控目标：最小 `44×44px`。

### 4.4 断点

- `0–479px`：小手机，单列，12px 页面边距。
- `480–767px`：大手机，单列，16px 页面边距。
- `768–1023px`：平板，双列可选，仍使用底部主导航。
- `1024–1279px`：桌面，固定侧栏 + 主内容。
- `≥1280px`：宽桌面，侧栏 + 最大 1200px 内容，不无限拉长行宽。

### 4.5 深色模式

默认跟随 `prefers-color-scheme`，设置页可选浅色、深色或跟随系统。深色模式重新定义面与状态色，不使用简单反相；阴影减弱、边框增强。代码通过 `data-theme` 覆盖系统偏好。

### 4.6 动效与 reduced-motion

- 快速反馈 `120ms`，普通过渡 `200ms`，面板切换上限 `320ms`。
- 统一曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 只动画 `opacity` 与 `transform`；不对高度和大面积模糊做持续动画。
- `prefers-reduced-motion: reduce` 时将动画和过渡降至近零，取消平滑滚动与装饰性运动；功能状态仍即时更新。

## 5. 响应式应用骨架

### 5.1 桌面

- 左侧固定侧栏：品牌、主要导航（今日、每日学习、测试、错题巩固、词典）及辅助入口（结果报告、设置）。
- 主区顶部：当前页面标题、业务日/本地日期、设置入口和 API 状态。
- 内容区：最大 1200px。今日页使用 `主任务区 + 右侧状态区`；长释义、报告和设置使用单主列或内容/目录双列。

### 5.2 手机和平板

- 顶部紧凑品牌栏：品牌名、页面标题、设置按钮。
- 主内容单列；关键信息先于次级说明，操作区不吸底遮挡内容。
- 底部导航：今日、学习、测试、巩固、词典，共五个主入口；高度包含安全区，点击目标不小于 44px。
- 结果报告作为测试流程二级页；设置由顶部入口进入。

## 6. 核心页面信息架构

### 6.1 首页 / 今日

**首屏必含**：本地日期、待学天数、今日学习包摘要、三条场景表达预览、明确的“整个待学包已学习”和“今天保持未学习”操作。

- 桌面：日期和问候 → 状态摘要 → 今日学习包与场景表达 → 欠学日期折叠组；右栏放操作说明。
- 手机：日期 → 待学天数 → 今日学习包 → 场景表达 → 两个状态操作 → 欠学折叠组。
- 欠学内容：每个 `<details>` 摘要显示日期、未结清文字和项目数；折叠只隐藏明细，摘要永远存在。

### 6.2 每日学习

- 桌面：日期分组时间线 + 右侧待学范围说明。
- 手机：今天优先，旧日期按时间倒序折叠；每组保留来源、内容版本和项目计数。
- 不提供逐卡“完成”造成假结清；唯一完成动作仍是整包结清。

### 6.3 测试

- 测试类型、题量和近期去重提示。
- 进行中状态显示“第 n / N 题”、题干、选项、明确未作答提示和下一步。
- 手机选项整行可点；桌面限制题干行宽。

### 6.4 结果报告

- 结论摘要：正确数、正确率、耗时、错题已进入巩固。
- 逐题结果同时使用“正确/错误”文本与颜色，不只显示红绿。
- 降级会话显示警告说明；不得展示“官方分数”。

### 6.5 词典

- 带可见标签的搜索框、提交按钮和词条来源链接。
- 单词头部显示词形、动词时态和音标；输入时显示联想词；下方按词性分组，保留全部释义、中文补充与例句。
- 桌面可有词性目录；手机仅折叠词性，不截断条目。

### 6.6 每日场景表达

- 三条表达按编号排列，先显示英文、词性与多个中文含义，再展开语义核心、场景、例句、误用提醒和替代说法。
- 桌面可双列组织场景；手机保持单列，不折叠掉关键中文说明。
- 信息密度优先，不增加无关插画或灰色免责声明。

### 6.7 错题复习

- 到期数、排序依据、学习项、最近错误原因和连续答对次数。
- 答题状态与掌握状态有文字；达到阈值后移至“已掌握”，不静默删除。

### 6.8 设置

- 学习计划：时区、开始日期、内容数量。
- 测试与巩固：题量、近期窗口、掌握阈值。
- 邮件：默认关闭、掩码地址、发送时段和周末策略。
- 外观与无障碍：主题、字号、减少动画、高对比度。
- Provider 与隐私：只显示连接状态和数据类别，不显示 secret。

## 7. 组件与可访问性约束

- `AppShell`：桌面侧栏、移动顶部栏和底部导航的唯一来源。
- `StatusTag`：必须含文字；`success/warning/error/info/neutral` 均有不同图形标记和边框。
- `LearningBundle`：日期分组使用原生 `<details>/<summary>`，支持键盘展开。
- `ActionPanel`：用 `aria-live="polite"` 宣布已学习/未学习状态；按钮使用 `aria-pressed`。
- `Progress`：同时显示文本分数和 `<progress>`，避免只看图形。
- 所有输入有 `<label>`；成组选择使用 `<fieldset>/<legend>`。
- `:focus-visible` 使用 3px 焦点环和 3px 间距，不能移除轮廓。
- 页面主标题唯一；导航使用 `aria-current="page"`；跳转链接允许键盘直接进入主内容。
- 手机底部导航为固定定位时，主内容增加足够底部内边距，不遮住末尾控件。

## 8. 发布前 UI 检查

- 320、375、768、1024、1440px 宽度无水平溢出。
- 浅色、深色、系统主题均可读；状态色在两种主题下均有非颜色提示。
- 键盘依次到达跳转链接、导航、页面内容和主要操作，焦点始终可见。
- reduced-motion 下没有非必要位移、闪烁或平滑滚动。
- 首页首屏在常见手机高度内能看到日期、待学天数、今日包、状态操作和场景表达摘要。
- 欠学日期折叠后仍显示日期、未结清状态和项目数。
- 自动可访问性扫描无严重/关键问题，并完成浏览器肉眼检查。
- 所有发布界面使用自然的学习语言，不出现合作、授权、题库来源或成绩保证暗示。
